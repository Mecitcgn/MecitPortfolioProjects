WeakSet ile gerçek hayat: Bir feed'de kartı yalnızca bir kez işleme

Bu örnek, sonsuz kaydırmalı bir arayüzde aynı kartı iki kez enhance etmemek için WeakSet kullanır. Kart DOM'dan silinirse, WeakSet onu zorla yaşatmaz; bu da onu UI tarafında çok uygun yapar.

Akış

Dışarıdan gelen kartlar sayfaya eklenir. Aynı kart yeniden taransa bile WeakSet sayesinde ikinci kez işlenmez.

Durum / Neden WeakSet?

Gerçek kullanım: Infinite scroll, dashboard widget enhancer, DOM sanitizer, form field decorator.
Neden WeakSet? Çünkü işaretlenen şeyler DOM node. Node sayfadan kalktığında state de gereksiz yere tutulmamalı.
Neden Set değil? Set, node referanslarını güçlü tutar ve bu da büyük UI’larda memory leak riskini artırır.
Neden Array değil? Üyelik kontrolü yavaştır ve GC ile uyumlu değildir.
