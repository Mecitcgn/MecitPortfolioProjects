Giriş: clip-path nedir?

CSS clip-path öğeyi kesmek (mask) için kullanılır. Bir elementin hangi kısmının görünür olacağını belirler. Performans açısından GPU hızlandırmalı olabilir ve modern tarayıcılarda (Chrome, Edge, Safari, Firefox) iyi desteklenir — fakat path() kullanımı ve bazı ileri tekniklerde tarayıcı farklılıkları gözlemleyebilirsiniz.

Bu site: her seviye için örnekler, canlı editör, önceden hazırlanmış snippet'ler ve animasyon örnekleri içerir. Sağ taraftaki canlı önizleme ile anında sonucu görebilirsin.

CSS sözdizimi

clip-path property birkaç form alır:

  • clip-path: inset(10px 20px 10px 20px round 8px);
  • clip-path: circle(40% at 50% 50%);
  • clip-path: ellipse(50% 30% at 50% 50%);
  • clip-path: polygon(x y, x y, ...);
  • clip-path: path('M...Z'); — SVG path (ileri)
  • clip-path: url(#svgMask) — SVG mask/clipPath referansı

Polygon — Çokgenler

Polygon en sık kullanılanıdır. Koordinatlar yüzde veya px ile verilir. 0 0 sol üst, 100% 100% sağ alt.

Örnek: Kart kesme 
clip-path: polygon(0 0, 100% 0, 100% 85%, 0 100%);
POLY

İpuçları:

  • Başlangıç için yüzde kullan: responsive olur.
  • İç içe transform uygularken transform-origin ile oynamak gerekebilir.
  • Tarayıcılar bazı durumlarda antialiasing farklılığı gösterebilir.

Circle / Ellipse / Inset

Circle örnek

CIRCLE

Inset örnek (iç marj)

Path() — SVG Path ile ileri şekiller

SVG path komutlarıyla (M, L, C, Q, A, Z) organik ve eğrisel formlar oluşturabilirsin. Path kullanımı DOM'da daha güçlü ama öğrenmesi biraz SVG path bilgisi gerektirir.

Örnek: Dalga 
clip-path: path('M0 0 L100 0 L100 70 Q70 100 50 90 Q30 80 0 100 Z');
WAVE

Not: path() içinde yüzdeleri kullanırken bazı tarayıcılar daha eski yorumlayabilir — test et. Alternatif olarak SVG <clipPath> tanımlayıp clip-path: url(#myClip) kullanmak daha esnek olabilir.

Animasyonlar ve Geçişler

clip-path property üzerinde transition ve animation kullanılabilir. Ancak path/complex değişiklikler performansa etki edebilir. Donanım hızlandırma için will-change: clip-path ekleyebilirsin.

Pulse morph örnek 
.demo-box{transition:clip-path .6s ease}
.demo-box:hover{clip-path:circle(60% at 50% 40%)}
HOVER

Daha ileri: SVG morphing (SMIL veya JS ile) ile de path lerin arasını yumuşatabilirsin (ör. flubber, anime.js). Ancak saf CSS ile path() morflamak tarayıcı desteği sınırlı olabilir.

Kısa Açıklamalar & İpuçları

  • will-change: clip-path; performans için ekle.
  • SVG fallback: tarayıcı uyumsuzluğu düşün. <clipPath> kullan.
  • Animasyon yaparken transition ekle; path morph bazı tarayıcılarda çalışmayabilir.
